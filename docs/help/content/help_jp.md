# 利用ガイド - Recette App

## 📖 レシピ管理 {#recipes}

### レシピを見る
メインメニューからレシピ一覧にアクセスできます。各レシピには以下が表示されます：

- レシピ名と画像

- デフォルトの人数

- レシピタイプ（PRO、MASTER、PERSOなど）

- 作成者

### レシピをフィルター
複数のフィルターオプションがあります：

- **イベントタイプ別:** ボタンをクリック（前菜、メイン、デザートなど）

- **作成者別:** ドロップダウンメニューを使用

- **テキスト検索:** レシピ名を検索バーに入力

- **食材別:** 食材名を入力すると、その食材を使用するすべてのレシピが表示されます

### 🌍 料理の国籍（国旗） {#nationality}

各レシピには国籍を設定でき、国旗の絵文字として表示されます。

**国旗が表示される場所:**
- レシピ一覧のカード（サムネイルの隅または名前の横）
- レシピ詳細ページ（準備時間・調理時間の情報の横）
- カレンダー（国籍が設定されている場合、カラードットの代わりに表示）

**国籍の設定方法:**

1. レシピの詳細ページを開く
2. 「✏️ 編集」をクリック
3. 基本情報セクションの「国籍」ドロップダウンから国を選択
4. 「保存」をクリック

**自動インポート:**
URLまたはPDFからのインポート時に、AIが料理の国籍を自動的に検出し、対応する国コードを提案します。

> **💡 ヒント:** インポート時に国籍が自動認識されない場合は、レシピの詳細ページから手動で設定できます。

### 🔗 レシピ間のリンク {#recipe-links}

食材を別のレシピにリンクできます。準備がそれ自体でデータベースのレシピである場合に便利です（例：「パイ生地」、「ベシャメルソース」、「鶏ブイヨン」）。

**食材をレシピにリンクする方法:**

1. 編集モードでレシピの詳細ページを開く
2. 食材リストの各行に「レシピにリンク」ドロップダウンが表示されます
3. このメニューでリンク先のレシピを選択
4. 保存

**表示への影響:**
- リンクされた食材には、クリック可能な **🔗 レシピ名** バッジが表示されます
- バッジをクリックすると、リンクされたレシピに直接アクセスできます

**重要:** リンクは**視覚的なもののみ**です。買い物リストでは、リンクされたレシピの食材は自動的に追加**されません**。表示される数量は必要な物理的な量（g、mlなど）のままです。

> **💡 例:** 「アップルパイ」レシピの「250gパイ生地」食材を「パイ生地」レシピにリンクできます。🔗バッジにより、買い物リストに自動的に含めることなく、生地のレシピにすばやくアクセスできます。

## 📅 食事カレンダー {#calendar}

カレンダーを使用すると、イベントとは独立して日常の食事を計画できます。

### カレンダーにアクセス
メインメニューから「カレンダー」をクリック。

### 食事を追加
1. カレンダーの日付をクリック
2. サイドパネルがその日の詳細とともに開きます
3. 「➕ 食事を追加」をクリック
4. 検索バーでレシピを検索（オートコンプリート）
5. タイミングを選択（朝食 / 昼食 / 夕食 / その他）
6. 国籍が設定されている場合、カレンダーのセルに国旗🌍とともに食事が表示されます

### カレンダーの食事タイプ
- **個人の食事**：データベースのレシピにリンク → 国旗🌍を表示
- **イベントの食事**：計画されたイベントから → 紫色で表示
- **フリーテキスト**：レシピにリンクしないクイックメモ → ⭐で表示

### ナビゲーション
- **◀ ▶** をクリックして月を変更
- 日付をクリックして詳細と計画された食事を確認
- 食事をクリックして削除

> **💡 ヒント:** カレンダーから、日付パネルの「イベントを作成」をクリックして直接新しいイベントを作成できます。日付は事前に入力されます。

## 🧾 レシート（領収書） {#receipts}

この機能を使用すると、レシートのPDFをインポートして、食材カタログの価格を自動的に更新できます。

### 仕組み
1. レシートを写真撮影またはスキャンしてPDFにする
2. AIが商品と価格を抽出
3. 食材とのマッチングを検証
4. カタログの価格が更新される

### レシートをインポート
1. メニューから「レシート」にアクセス
2. 「📤 レシートをインポート」をクリック
3. PDFファイルを選択
4. AIがレシートを分析し、食材とのマッチングを提案

### マッチングの検証
1. リストからインポートされたレシートを開く
2. 検出された各商品について：
   - **検証**：食材が一致する → 価格が記録される
   - **検証して適用**：検証してカタログの価格も更新
   - **修正**：マッチングが正しくない場合、正しい食材を選択
3. 「すべての検証済み価格を適用」をクリックして一括更新

> **💡 ヒント:** レシートを検証すればするほど、カタログが正確になり、予算見積もりの信頼性が高まります。

## 📥 レシピのインポート {#import}

データベースにレシピを追加するための3つのインポート方法があります。

### URLからのインポート（推奨）
ウェブサイト（料理サイトなど）から直接レシピをインポート：

1. メニューの「URLからインポート」にアクセス
2. レシピページのURLを貼り付け
3. 対象言語（FRまたはJP）を選択
4. 「分析」をクリック
5. AIが抽出：タイトル、食材、手順、時間、人数、**国籍**
6. 必要に応じて情報を確認・修正
7. 「保存」をクリック

### PDFからのインポート
PDF形式のレシピ（デジタル化されたレシピ本など）：

1. メニューの「PDFからインポート」にアクセス
2. PDFファイルを選択
3. AIがPDFを分析してレシピを抽出
4. 情報を確認して保存

### CSVインポート
一度に大量のレシピをインポート：

1. メニューの「CSVインポート」にアクセス
2. 必要な形式でCSVファイルを準備
3. ファイルをアップロード

> **💡 ヒント:** URLインポートが最も簡単で信頼性の高い方法です。AIが自動的に言語と料理の国籍を検出します。

## 🏷️ カテゴリーとタグ {#categories}

カテゴリーとタグにより、レシピを整理して簡単に見つけられます。

### カテゴリーとタグの違い
- **カテゴリー**：主な分類（例：メインディッシュ、デザート、前菜）
- **タグ**：自由なキーワード（例：簡単、ベジタリアン、グルテンフリー、家族のレシピ）

### レシピにカテゴリー/タグを割り当て
1. レシピの詳細ページを開く
2. 「✏️ 編集」をクリック
3. 「カテゴリー」または「タグ」セクションで対応するエントリーをチェック
4. 保存

### カテゴリーとタグの管理（管理者）
メニューから「タグの管理」にアクセス：
- 新しいカテゴリーまたはタグを作成
- 名前と色を変更
- 未使用のエントリーを削除

### カテゴリーまたはタグでフィルター
レシピ一覧から、フィルターを使用して特定のカテゴリーまたはタグのレシピのみを表示。

## 🔍 食材で検索 {#search}

### どのように機能しますか？
この機能を使用すると、指定した**すべて**の食材を含むレシピを見つけることができます。

### 使い方

1. レシピページで、緑色の「食材で検索」ブロックを見つけます 🥕

2. カンマで区切って食材を入力します：`トマト、バジル、モッツァレラ`

3. 「検索」をクリックするか、Enterキーを押します

4. **これらすべての食材**を含むレシピのみが表示されます

5. 「クリア」をクリックして完全なリストに戻ります

> **💡 ヒント:** レシピが見つからない場合は、食材を減らすか、スペルを確認してください。

## 👥 参加者とグループの管理 {#participants}

### 参加者を作成

1. メインメニューから「参加者」ページにアクセス
2. 「➕ 新規参加者」をクリック
3. 情報を入力:

   - **名前**（必須）
   - **名**
   - **役割**（例：ゲスト、スタッフ、講演者）
   - **電話番号**
   - **メール**
   - **住所**

4. 「保存」をクリック

### 参加者グループを作成

グループを使用して参加者を整理できます（例：「田中家族」、「マーケティングチーム」）:

1. 「参加者」ページで「➕ 新規グループ」をクリック
2. グループ名を入力（必須）
3. 説明を追加（オプション）
4. 「保存」をクリック

### グループに参加者を追加

グループの詳細ページから:

1. **グループ名をクリック**して詳細ページにアクセス
2. **「参加者を追加」セクション**（上部）:
   - グループに追加したい参加者をチェック
   - 既にメンバーの参加者はこのリストに表示されません
3. **「現在のメンバー」セクション**（下部）:
   - グループの全メンバーのリスト
   - ❌をクリックしてメンバーを削除

### 参加者のグループを表示

参加者の詳細ページから:

1. **参加者名をクリック**して詳細ページにアクセス
2. **「グループ」セクション**に所属する全グループが表示されます
3. ❌をクリックしてグループから参加者を削除できます

> **💡 ヒント:** 参加者は複数のグループに同時に所属できます。

### マルチユーザー分離

各ユーザーは自分の参加者とグループのみを表示できます。管理者はすべてのユーザーのすべての参加者とグループを表示できます。

## 📅 イベント管理 {#events}

### イベントとは？

**イベント**とは、ある人数のために1日または数日間の料理を準備するために必要なものを、ひとつにまとめたものです。友人との食事会、ご招待、料理教室（**マスタークラス**）や**プロ**向けのお仕事などに使います。

イベントでできること：

- 🍽️ レシピの中から**作る料理を選ぶ**
- 📆 **料理を1日または複数の日に割り当てる**（各日の人数も設定できます）
- 🛒 **買う材料のリストを作る**：人数に合わせて分量が自動で計算されます。印刷したり、スマホに送ったりできます
- 🖨️ **レシピを印刷する**：分量は人数に合わせて調整されます。料理教室の参加者に配るのに便利です
- 👥 **参加者を登録する**、💰 **予算を管理する**（予定と実際の支出）

> **📌 例:** 10人で2日間のマスタークラスの場合：教室で作るレシピを選び、土曜日と日曜日にそれぞれ何を作るかを決めると、アプリが買い物リストを計算し、印刷用のレシピを準備します。

### イベントを作成する

イベントの作成方法は2つあります：

- **✨ かんたん作成**（おすすめ）：作成から買い物リストまで、5つの簡単なステップで進めます。**マスタークラス**（料理教室）や**プロ**向けの準備に最適です。
- **➕ 新しいイベント**：すべての情報（場所、メモなど）を一度に入力するフォームです。

どちらの方法でも同じイベントが作成されます。作成後はイベントのページから参加者、予算、レシピの印刷などを追加・変更できます。

### ✨ かんたん作成（おすすめ） {#event-wizard}

**開き方：** イベント一覧の上にある青いボタン **✨ かんたん作成**、またはメニューの「イベント」内の **✨ かんたん作成** をクリックします。

画面の上に5つの丸があり、今どのステップにいるかを示します：

**1 名前 → 2 日付 → 3 レシピ → 4 献立 → 5 買い物**

- 🔵 現在のステップ — 🟢 ✓ 完了したステップ
- イベントが作成された後（ステップ2の後）は、**丸をクリックして好きなステップに戻れます**。入力した内容は自動で保存されます。
- 画面下の **← 戻る** と **次へ →** ボタンでも前後に移動できます。

**あとで続きをする：** イベントのページにある青いボタン **✨ かんたん作成** を押すと、ステップ3（レシピ）から再開できます。レシピの追加、日付の割り当ての変更、買い物リストの確認がいつでもできます。通常のフォームで一部の日（例：週末）の選択を外したイベントでは、このボタンは表示されません。その場合はイベントのページから変更してください。

#### ステップ1 — 名前

1. **イベントの名前は？** 例：「12月の料理教室」
2. **何人分ですか？** 通常の参加人数（初期値は10人）
3. **イベントの種類は？** **プロ**、**マスタークラス**、**ご招待** などをタップ
4. **次へ →** をクリック（種類を選ぶまでボタンは押せません）

> **💡 ヒント:** 種類はただのラベルではありません。ステップ3で、その種類でよく使うレシピが最初に表示されます。

#### ステップ2 — 日付

1. **1日だけ** または **数日間** を選ぶ
2. **日付**、または **初日** と **最終日** を入力（最大60日）
3. **各日の人数は？** 各日はステップ1の人数になっています。**人数が違う日だけ変更してください**（例：土曜日は8人、日曜日は12人）。
4. **次へ →** をクリックすると、イベントが作成されます。

> **⚠️ 注意:** 後で日付を変更すると、「どの日に何を作るか」（ステップ4）の設定が消えるため、やり直す必要があります。ある日の人数だけを変更した場合は、設定はそのまま残ります。

#### ステップ3 — レシピ

1. **レシピをタップして選択**（緑色になります）。もう一度タップすると取り消せます。
2. 上のフィルターを使います：
   - **すべて**：すべてのレシピ
   - **プロ**、**マスタークラス** など：その種類に関連付けられたレシピ
   - **✓ 選択済み (X)**：選んだレシピだけを表示して確認
   - **🔍 レシピを検索…**：名前で検索
3. **すべて選択（X品）** で、表示中のレシピをまとめて選択できます。ある教室のプログラムを丸ごと選んでから、不要なレシピを外すと便利です。
4. **X品・次へ →** をクリック

レシピに付く目印：

- **★ おすすめ**：イベントの種類に関連付けられたレシピ
- **⚠️ 材料なし**：材料が登録されていないレシピ。**買い物リストには表示されません**

#### ステップ4 — 献立（どの日に何を作りますか？）

このステップは**数日間**のイベントのときだけ表示されます。1日だけの場合は、すべてのレシピが自動でその日に入り、そのまま買い物リストへ進みます。

1. レシピごとに、作る**日付をタップ**します（緑色になります）。各ボタンにはその日の人数が表示されます。
2. **毎日**：そのレシピを毎日作ります。
3. 日付のないレシピがあっても大丈夫です（メッセージが表示されます）。あとで設定できます。
4. **次へ →** をクリック

**分量はその日の人数に合わせて計算されます：**

- 土曜日（8人）に作るレシピ → **8人分**
- 土曜日と日曜日（8人＋12人）に作るレシピ → **20人分**
- 日付のないレシピ → ステップ1の人数分

#### ステップ5 — 買い物

**✓ 完成しました！** と表示され、レシピの数と各日の人数、自動で計算された買い物リストが表示されます。

- 買わないもの（例：在庫のある塩、油、醤油）は**チェックを外します**
- 行の中で**数量や単位を直接変更**できます。すぐに保存されます
- ⚠️ で「材料が登録されていない」レシピが表示された場合、そのレシピはリストに入っていません。レシピのページから材料を追加してください

画面下のボタン：

| ボタン | 動作 |
|--------|------|
| 📱 スマホに送る | スマホやタブレットで共有メニュー（LINE、メッセージ、メールなど）を開きます。パソコンではファイルとして保存されます。 |
| 💾 リストを保存 | リストをテキストファイル（.txt）でダウンロード |
| 🖨️ リストを印刷 | 買い物リストを印刷 |
| 📖 レシピを印刷 | 分量を調整した[レシピ詳細](#recipes-print)を開いて印刷 |
| 完了 ✓ | イベントのページを開く |

チェックを外した材料は、印刷・送信・保存されません。

> **📌 例 — 週末2日間のマスタークラス:**
> 1. 名前：「韓国料理教室」、10人、種類 **マスタークラス**
> 2. 数日間：14日（土）→ 15日（日）。土曜日は8人、日曜日は12人
> 3. フィルター **マスタークラス** → **すべて選択** → 予定にないレシピを外す
> 4. チャプチェは土曜日、プルコギは日曜日、キムチは **毎日**
> 5. チャプチェは8人分、プルコギは12人分、キムチは20人分で計算されます。塩と油のチェックを外し、買い物に出る前に **📱 スマホに送る**。

### ➕ 通常の作成（フォーム）

イベントのすべての情報を一度に入力する場合：

1. イベント一覧から「新しいイベント」をクリック

2. 情報を入力：名前、日付、場所、参加者数

3. **イベントタイプを必ず選択してください** — デフォルトではタイプは選択されていません。タイプを選択せずに「保存」をクリックすると、選択を促すメッセージが表示されます。

4. 必要に応じてメモを追加

5. 「保存」をクリック

### イベントをコピー
既存のイベントから新しいイベントを素早く作成：

1. イベント一覧で、複製したいイベントの横にある「コピー」をクリック

2. フォームには元のイベントのすべての情報が事前入力されます

3. 名前、日付、場所、その他の必要な情報を変更

4. 元のイベントの日数が保持されます

5. 開始日を入力：終了日が自動的に計算されます

6. 確認して新しいイベントを作成

**コピーされるもの:**

- ✅ すべてのレシピと調整された数量

- ✅ 予定予算と通貨

- ✅ レシピの組織/プランニング（同じ日数の場合）

**コピーされないもの:**

- ❌ 実際の経費

- ❌ 買い物リスト（自動的に再生成されます）

> **💡 ヒント:** 元のイベントで日を選択解除している場合（例：週末）、選択された日のみがプランニングのコピーに考慮されます。

### イベントにレシピを追加

1. イベントを開く

2. 「レシピを追加」をクリック

3. リストからレシピを選択

4. 必要に応じて人数を調整

### イベントの参加者を管理

イベントに登録された参加者を追加・管理します:

1. **イベント一覧からイベントを開く**
2. **ページ上部の「参加者 (X)」ボタンをクリック**
3. **モーダルウィンドウ**が2つの列で開きます:

   **左列 - 参加者を追加:**
   - **個別参加者:** 名前の横のチェックボックスをチェックして個人を追加
   - **グループ全体:** グループ名の横のチェックボックスをチェックして全メンバーを一度に追加
   - 既に登録されている参加者/グループはこのリストに表示されません

   **右列 - 登録済み参加者:**
   - イベントに既に登録されているすべての参加者のリスト
   - **出所の表示:**
     - 個別に追加された場合: 名前のみ
     - グループ経由で追加された場合: "via グループ: [グループ名]"
   - **参加者を削除:** 名前の横の赤い❌をクリック

4. **自動保存:** 追加と削除は即座に記録されます

> **💡 ヒント:** グループ経由で追加された参加者を削除すると、不整合を避けるためにページがリロードされます。個別に追加された参加者は即座に削除できます。

> **📌 注意:** イベントに追加する前に、「参加者」メニューから参加者とグループを作成する必要があります。

### 🖨️ レシピ詳細（印刷） {#recipes-print}

この機能により、イベントのすべてのレシピを、参加者数に応じて自動調整された食材量とともに表示・印刷できます。

**典型的な使用例：** PROワークショップを開催する際、グループの人数に合った正確な分量でレシピカードを参加者に配布したい場合。

**レシピ詳細にアクセスする方法：**

1. イベント一覧からイベントを開く
2. **🖨️ レシピ詳細**ボタンをクリック（ティール色のボタン。レシピが1件以上ある場合に表示）
3. 専用ページが開き、すべてのレシピが一覧表示されます

**各レシピカードの内容：**

- レシピの写真（設定されている場合）
- 名前と番号（例：1/3）
- 倍率の表示（例：「基準4人分 → ×2.5（10名分）」）
- 参加者数に合わせて再計算された食材と分量
- 完全な調理手順

**印刷する方法：**

ページ上部または下部の **🖨️ 印刷** ボタンをクリックしてください。

- レシピごとに1ページで印刷されます
- ナビゲーションバーは印刷されません
- インク節約のため、白背景・黒文字で印刷されます

> **💡 ヒント:** 印刷された各ページには、イベント名と参加者数が記載されており、参加者への配布が簡単です。

## 🛒 買い物リスト {#shopping}

### 自動生成
買い物リストはイベントのレシピから自動生成されます：

- 食材がグループ化され、合計されます
- 単位は可能な場合自動変換されます
- **サブレシピも材料に展開されます**：あるレシピが別のレシピを使う場合（例：親子丼の中のとりかつ）、そのサブレシピの材料もリストに追加されます
- 分量は、レシピを作る**各日の人数**に合わせて計算されます
- 参加者数、日付、レシピを変更するとリストが更新されます
- 更新時やイベントのコピー時にも、**あなたの変更は保持されます**（チェックを外した材料、手で変更した数量）

### 使用方法

1. イベントを開き、**📝 材料リスト** をクリック（または[かんたん作成](#event-wizard)のステップ5）
2. **買わないもののチェックを外します**：取り消し線が付き、印刷・送信・予算に含まれません。**☑ すべて選択** と **☐ すべて解除** でリスト全体を切り替えられます。
3. 材料の横の **✏️ 編集** で、数量、単位、価格を変更したり、**購入済** にチェックしたりできます
4. **📱 スマホに送る**：スマホやタブレットの共有メニュー（LINE、メッセージ、メールなど）を開きます。パソコンではファイルとして保存されます。
5. **💾 保存**：リストをテキストファイル（.txt）でダウンロード

## ✅ レシピとコストの確認

### 🔍 ステップ 1 : レシピを確認

正確なコスト計算を保証するために、各レシピを確認してください：

1. **レシピ一覧から各レシピを開く**

2. **食材の単位を確認**

   - 単位は実際の使用に対応する必要があります（ml、g、大さじ、個など）

   - 例：だし → ml（レシピ内）

3. **特別な注意が必要な食材をメモ**

### 💰 ステップ 2 : 価格カタログを確認

レシピで使用される各食材について：

1. **価格カタログにアクセス**

2. **各食材の購入単位を確認**

   - 単位は実際のパッケージに対応する必要があります

   - 例：だし → 30g（袋）、バター → 250g（ブロック）

3. **価格と数量を確認**

   - 価格：購入時に支払った金額

   - 数量：パッケージの内容量

   - 例：だし 30g = 5.01€

### 🔄 ステップ 3 : 特定の変換を管理

一部の食材は購入と使用の間で形態が変わります：

**特定の変換をいつ使用するか？**

- 食材が一つの単位（g）で購入されるが、別の単位（ml）で使用される

- その食材に対する標準的な容量↔重量の変換が存在しない

- 例：だし粉（g） → 液体スープ（ml）

**特定の変換を追加する方法:**

1. メニューから「**食材別特定変換**」にアクセス

2. 「**➕ 追加**」をクリック

3. 情報を入力:

   - **食材**: 正確な名前（例：だし）

   - **から**: カタログの単位（例：g）

   - **へ**: レシピの単位（例：ml）

   - **係数**: 変換比率（例：33 = 1g → 33ml）

   - **備考**: 説明（例：「30gの粉 → 1000mlのスープ」）

**特定の変換の例:**

- **だし**: 1g → 33ml（粉30g = スープ1000ml）

- **ブイヨンキューブ**: 1個 → 500ml（1個 = スープ500ml）

- **マッシュルーム**: 1g → 1缶（包装変換）

### 💡 ステップ 4 : レシピのコストを確認

変換を設定したら：

1. **レシピを開く**

2. **レシピの詳細ページで自動計算されたコストを確認**

   - レシピの合計コストが自動的に表示されます

   - 一人当たりのコストは人数に応じて計算されます

   - **主な目的**：食材ごとの金額が正しいことを確認する

3. **金額の整合性を確認**:

   - 合計コストは現実的である必要があります

   - 一人当たりのコストは一貫している必要があります

   - 特定の変換を持つ食材は正しい価格を表示する必要があります

   - 金額が正しくない場合は、カタログの価格と単位を確認してください

**確認例（だし）:**

- ✅ レシピ : 250mlのだし

- ✅ カタログ : 30g = 5.01€

- ✅ 変換 : 1g → 33ml

- ✅ 計算 : 250ml ÷ 33 = 7.58g → 7.58g × (5.01€/30g) = **1.27€**

- ❌ 41.75€と表示される場合 → 特定の変換が設定されていません

### 📊 ステップ 5 : イベントの予算を確認

既存のイベントについて：

1. **イベントを開く**

2. 「**予算**」をクリック

3. **買い物リスト**と計算された価格を確認

4. 価格は必要な実際の数量に対応する必要があります

5. 価格が正しくないように見える場合は、以下を確認してください:

   - カタログの価格

   - 必要に応じて特定の変換の存在

   - 使用されている単位（レシピ vs カタログ）

## ❓ よくある質問

### イベント作成後に参加者数を変更できますか？
はい！買い物リストと数量が自動的に更新されます。

### 食材検索は少なくとも1つの食材を含むレシピを見つけますか、それともすべての食材ですか？
すべての食材です！AND論理です。「トマト、バジル」を検索すると、トマトとバジルの両方を含むレシピのみが表示されます。

### 特定の日だけレシピを計画できますか？
はい！イベント作成時に、作業しない日（週末、祝日）の選択を解除してください。選択された日付のみがプランニングに表示されます。

### カタログの価格は必須ですか？
いいえ、オプションです。カタログは主に新しいイベントで価格を提案して時間を節約するために使用されます。

### 「かんたん作成」と「新しいイベント」、どちらを使えばいいですか？
**✨ かんたん作成** が一番簡単です。名前、日付、レシピ、献立、買い物リストを順番に進めます。**➕ 新しいイベント** は、場所やメモなどを一度に入力したいときに使います。どちらで作っても、あとでイベントのページから変更でき、ページの **✨ かんたん作成** ボタンで続きを進めることもできます。

### 日付を変えたら、レシピの日付の割り当てが消えました。なぜですか？
日付を変えるとイベントの日が作り直されるため、「どの日に何を作るか」の設定が消えます。かんたん作成の **4 献立** をやり直すか、[プランニング](#planning)を使ってください。ある日の人数だけを変えた場合は消えません。

### レシピが買い物リストに出てきません。なぜですか？
そのレシピに材料が登録されていない（**⚠️ 材料なし** の目印）か、材料のチェックが外されています。レシピのページで材料を追加するか、リストで材料にもう一度チェックを入れてください。

### 買い物リストをスマホに送るには？
**📱 スマホに送る** ボタンを押します。スマホやタブレットでは、送り先のアプリ（LINE、メッセージ、メールなど）を選びます。パソコンでは .txt ファイルとして保存されるので、それを自分に送ってください。

### レシピの国籍はどうやって変更しますか？
レシピの詳細ページを開き、「✏️ 編集」をクリックし、「国籍」ドロップダウンから国を選択して保存してください。

### デフォルト言語を変更するにはどうすればいいですか？
プロフィールページを開き、下部の 🇫🇷 Français または 🇯🇵 日本語 をクリックしてください。設定が保存され、次回ログインから自動適用されます。

### 「レシピ詳細」ボタンがグレーアウトされているのはなぜですか？
イベントにレシピが1件以上ある場合にのみ有効になります。先にイベントにレシピを追加してください。

### イベントタイプは必須ですか？
はい、必須です。デフォルトでは選択されていないため、保存前に必ず選択してください。選択せずに保存しようとすると、メッセージが表示されます。
